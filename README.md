# DramaBox

[下载最新版 Windows 安装包](https://github.com/sabermasterlc/dramabox-desktop-releases/releases/latest)

安装后即可使用。已有0.9.0及以上版本，可点击软件顶部“软件更新”。

每个版本只保留两项附件：
- setup.exe：安装包，用户下载这个即可。
- latest.json：自动更新清单，供软件读取，无需手动下载。

更新说明在发行页正文中。软件启动时检查新版本，下载和安装由用户决定。

此仓库仅用于发行，应用源码和签名私钥保留本地。GitHub自动生成的Source code链接仅打包本仓库的README。
