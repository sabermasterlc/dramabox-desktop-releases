# AI 字幕翻译

[返回项目首页](../README.md) · [下载 Windows 0.15.6 AI 字幕正式版](https://github.com/sabermasterlc/dramabox-desktop-releases/releases/tag/v0.15.6)

在播放器中打开「AI 翻译」，先为当前整集准备字幕，再观看。默认启用 AI 字幕与自动预处理下一集；处理耗时取决于字幕来源、片长、模型和电脑性能，不保证实时完成。

![AI 字幕翻译设置](screenshots/ai-subtitles.png)

## 从哪里取得字幕？

软件优先使用片源提供且可读取的字幕文件；没有可用字幕时，读取获准播放的本集音频，在本机识别后翻译。也可以导入 SRT / VTT。画面中已经烧录的文字不属于字幕文件，仍需音频识别；识别与翻译可能有遗漏或错误。

## 语言和显示方式

- 本地大模型提供中文、英语、日语、韩语之间的目标语言选择；识别来源可以自动检测或手动指定。
- 「目标语言」决定翻译成什么语言；「显示内容」独立选择仅译文、仅原文或原文 + 译文。
- 基础本地翻译仅用于英 → 中；其他方向使用本地大模型。可维护本剧人物词表，帮助统一姓名和称呼。
- 支持整集处理、本机缓存、任务取消、重新生成，以及 SRT / VTT / CSV 导出。切换语言需要生成对应译文。

## 自动准备下一集

保持「自动预处理下一集」开启，软件会在条件满足时排队处理可访问的下一集，减少切集等待。无需每一集手动点按钮；也可关闭自动处理。视频或字幕不可读、当前任务未结束、下一集需要授权等情况会影响预处理，不能据此越过官网章节授权。

## 自定义字幕样式

![字幕字体、背景和位置设置](screenshots/subtitle-style.png)

在「设置 → AI 字幕 → 打开 AI 字幕设置」中下载 / 修复组件，并使用预览图调整样式。播放器的「AI 翻译 → 样式」与此处共用设置。

在「样式」中设置字体、字号、文字颜色、加粗、描边、背景颜色和透明度；调整水平 / 垂直位置，或启用位置编辑后拖动。位置以整个播放窗口为准，支持左右黑边区域；可选择按字数换行、自动换行或不自动换行，并设置每行字数和字幕最大宽度。设置保存在本机，可按观看习惯调整。播放条默认保留常用功能，其余按钮可在播放器设置中选择显示。

## 首次安装与空间

Windows x64 0.15.6 安装包约 **23.7 MB**，AI 模型与运行环境独立下载。首次使用时阅读并同意模型条款后，由软件自动下载约 **3.16 GB** 的基础组件；建议至少 **16 GB 内存**，安装时预留 **12 GB 可用空间**。组件下载完成后会校验文件并实际运行识别与翻译检查，不需要用户另行安装 Python。

下载中断保留进度，可重试；下载站点不可达时需要可用网络。可在首次配置时选择额外 NVIDIA 加速组件，约 **553 MB**。GPU 能否使用取决于显卡、驱动和兼容性；支持 CPU 路径，自动模式会尝试兼容的 GPU。

组件准备好后，识别与翻译在本机运行，无需 API Key 或按 token 付费。片库与在线视频仍需联网。离线部署可由维护者提供完整便携目录；不要只复制主程序而漏掉组件目录。

## 验证范围

Windows 已验证匿名公开下载、中断恢复、独立空目录安装、文件校验、CPU 识别和中英双向翻译，以及公开样片的音频识别链路。不同显卡、网络及各种语言的长片质量仍需持续验证，翻译结果不保证逐词准确。详见 [0.15.6 发行页](https://github.com/sabermasterlc/dramabox-desktop-releases/releases/tag/v0.15.6)。
